# Sistema Inteligente de Gestão para a Da Roça

## Sobre o projeto

O projeto tem como objetivo desenvolver um sistema inteligente
para auxiliar a empresa Da Roça – Agropecuária & Pet no controle
de estoque e na identificação de produtos que precisam ser repostos.

## Problema identificado

A empresa apresenta dificuldades no acompanhamento do estoque,
na identificação de produtos com maior saída e na reposição
antecipada de mercadorias.

## Solução proposta

Desenvolver um sistema web que utilize dados de vendas e estoque
para gerar informações e auxiliar na tomada de decisões.

## Tecnologias previstas

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Git e GitHub

## Base de dados

Foi selecionada uma base pública do Kaggle:

Retail Store Inventory Forecasting Dataset

Link:
https://www.kaggle.com/datasets/anirudhchauhan/retail-store-inventory-forecasting-dataset

A base possui 73.100 registros e 15 variáveis, relacionadas
a estoque, vendas, produtos e previsão de demanda.
